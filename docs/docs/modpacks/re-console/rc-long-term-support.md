# Re-Console LTS (long-term support)
Releases of Re-Console using the original multi-version strategy are known as Re-Console LTS, also known as [Long-term support](https://en.wikipedia.org/wiki/Long-term_support)

While Re-Console+ has far more features and only releases for the Fabric modloader on the latest Minecraft version available for the majority of our feature mods, Re-Console LTS supports multiple different versions of the game with multiple different modloaders.

These versions may not be eligible for full support as they are built on different versions and very different sets of mods. Use at your own risk!
