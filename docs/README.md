# Reverie Projects Documentation

Documentation for projects under Reverie Projects

**The documentation is hosted on [docs.nostalgica.net](https://docs.nostalgica.net/) and is automatically updated nightly.**

**This repository is hosted on [git.nostalgica.net](https://git.nostalgica.net/reverie-projects/monorepo) and mirrored on [GitHub](https://github.com/Nostalgica-Reverie/Content-Monorepo).**

The Lasting Legacy Documentation is powered by [VitePress](https://vitepress.dev/), and most pages are written in [Markdown](https://en.wikipedia.org/wiki/Markdown).

To run the docs on your own machine for contribution purposes:

- Install [Bun](https://bun.sh/) 1.3.14
- Install the monorepo dependencies from the repository root

```
bun install
```

- Start the local development server

```
bun run --cwd docs docs:dev
```
