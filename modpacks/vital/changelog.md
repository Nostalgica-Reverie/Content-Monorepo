# Vital 26.05
Wow, this project is back from the dead! Now under Reverie Projects, the creators of Re-Console+, Legacy4J, etc.

## What's New
- Vital has been updated to 26.1.2! This brings us to the latest version of Minecraft
- Vital now uses CalVer, in line with our other projects
- Vital has added in a few new mods to enhance the experience, like Sounds, while porting directly from 2.2.2 (for 1.21.4)
- Vital has been updated to Additive 26.1.4, and will remain in sync with the project.

## What comes next
I plan to release more patches expanding upon the modpack, alongside porting the new version to CurseForge.

## Reverie Projects Transition
The project is no longer affiliated with the now defunct NotEssential & Vital org, and is separate. I used to maintain Vital in the end of its previous development, so the pack wont change that much from its vision ;)
