# Reminiscence 2.0.0-hotfix
This is a minor release to 2.0.0 which improves performance, fixes licensing issues found on Modrinth, and updates mods. This is the first update done in conjunction with Reverie Projects and Bali.

## Added zFastNoise
This mod can improve world-gen speeds by upwards of 20%.

## Added Krypton Reno
Replaced Krypton Forgified or whatever was used before - maintained and a bit faster.

## Added Missing Mods Checker (Modrinth)
This also prompts you to install the few missing mods from the CurseForge version, allowing it to have 100% parity and avoid massive licensing issues that could get the pack taken down entirely.

## Added Particle Core
Improves performance for particles. Config taken from Simply Optimized Forked v26.06.8

## Added Structure Layout Optimizer
Improves jigsaw structure generation.

## Added Ixeris
Optimizes input. Config taken from Simply Optimized Forked v26.06.8

## Added Async Logger
Async Logger can improve logging performance by 43x

## Added Gnetum
Gnetum optimizes GUI's via batching and FPS limiting. FPS capped to 60.

## Added Immersive Optimization
Relatively large TPS improvements in edge cases :)

## Compressed Images
Ran all images in the modpack through oxipng. 

## Updated Crash Assistant Config
This was based off of Re-Console & Simply Legacy's Crash Assistant config, and now it starts recommending support in Bali's discord server.

## Updated servers.dat
Now includes the official Remi SMP by default.

## Ported to Packwiz/Packwand
Reminiscence is now available as a Packwand project on Forgejo, Codeberg and GitHub. Packwand is our custom fork of packwiz designed for monorepos. You can find our new source code here: https://git.nostalgica.net/Reverie-Projects/monorepo/src/branch/main/modpacks/reminiscence
